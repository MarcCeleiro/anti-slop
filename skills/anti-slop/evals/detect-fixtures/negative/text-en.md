# Release notes

## Search

Search now matches words inside PDF attachments, so you can find a contract by a phrase you remember from it.

When you rename a folder, links that point to it keep working. If you delete it, the links show a message with the date it was removed.

The export runs at night and usually takes ten minutes. We email the file to the account owner when it is ready.

We fixed a bug that duplicated invoices when two people saved the same draft at once.
